# Security

Report vulnerabilities using the repository's private security reporting channel
when available. Do not publish credentials, private runtime data, game material,
or live-target exploit details in issues.

Persistence and current authority are prerequisites for new mutation admission.
Uncertain effects remain unresolved until authoritative evidence exists. Local
endpoints require authentication and separate read, lifecycle, recovery and admin
capabilities. Approved executables and release digests are immutable inputs.

Development state and sensitive runtime state must remain outside committed source.
Service deployment and destructive host tests require an approved disposable host.
